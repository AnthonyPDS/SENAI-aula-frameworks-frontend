# Descrição

Ao final desta unidade curricular, o estudante será capaz de programar aplicações responsivas para a internet, tendo em vista a utilização em ambientes industriais de produção.

Serão abordados os seguintes conteúdos:

- Tecnologias Front-end
- Framework para CSS
- Framework para Front-end

---

# Objetivo

Programar aplicações responsivas para a internet, tendo em vista a utilização em ambientes industriais de produção.

---

# Capacidades Técnicas

- Configurar o ambiente de desenvolvimento para aplicações Web.
- Aplicar tecnologias front-end na programação da interface do usuário.
- Elaborar códigos de programação Web, respeitando boas práticas e convenções de desenvolvimento.
- Definir frameworks para programação conforme a necessidade da linguagem utilizada.
- Criar aplicações web de acordo com princípios de UX e responsividade.

---

# Capacidades Socioemocionais

## Ética

- Demonstrar comportamento ético na conduta profissional.
- Respeitar princípios, diferenças individuais e justiça social.
- Valorizar o meio ambiente.

## Pensamento Crítico e Inovação

- Expressar-se de forma crítica, utilizando evidências claras.
- Avaliar fatos, ideias, opiniões e diferentes perspectivas.

## Resolução de Problemas Complexos

- Reconhecer demandas.
- Propor soluções para problemas profissionais.
- Demonstrar postura proativa.
