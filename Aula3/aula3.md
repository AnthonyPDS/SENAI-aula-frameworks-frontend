# Aula 3 — Comparativo de frameworks front-end

React, Vue, Angular e Next.js ajudam na construção de aplicações web modernas, mas possuem propostas e níveis de estrutura diferentes.

| Critério | React | Vue | Angular | Next.js |
|---|---|---|---|---|
| **O que é?** | Biblioteca para construir interfaces com componentes. | Framework progressivo para interfaces web. | Framework completo para aplicações web robustas. | Framework React para aplicações full-stack. |
| **Linguagem comum** | JavaScript ou TypeScript | JavaScript ou TypeScript | TypeScript | JavaScript ou TypeScript |
| **Organização** | Flexível; o desenvolvedor escolhe ferramentas adicionais. | Progressiva; os recursos podem ser adotados conforme a necessidade. | Opinativa; possui estrutura e convenções bem definidas. | Baseada em rotas, páginas e componentes React. |
| **Ponto forte** | Ecossistema amplo e componentes reutilizáveis. | Curva de aprendizado suave e boa produtividade. | Padronização, escalabilidade e ferramentas integradas. | Renderização híbrida, rotas e otimização para produção. |
| **Ideal para** | SPAs, produtos digitais e interfaces reutilizáveis. | Projetos pequenos, médios e protótipos rápidos. | Times grandes e sistemas corporativos complexos. | Sites com SEO, conteúdo e aplicações full-stack. |

## Conclusão

Não existe uma tecnologia universalmente melhor. A escolha depende do tamanho do projeto, da experiência da equipe, da necessidade de renderização, do SEO e da complexidade da aplicação.
